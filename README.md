# V5 버티포트 풍향·풍속 예측 (데모)

킨텍스 V5 버티포트 예정지의 수평 분포, 연직 단면(Y축·X축), 48시간 예측 추이와 이·착륙 풍 경고를 보여주는 정적 웹앱입니다. GitHub Pages로 배포합니다.

## 현재 상태
- **데모 단계.** 시간 변화는 합성 데이터입니다. 기준장은 MUKLIMO_3 민감도 실험 1개 케이스(12 m/s, 0°)입니다.
- 격자 160×160, 10 m 간격, 18층(5–600 m). V5 중심은 격자 (85,75) (1-based).
- 유입풍 1.5배 문제가 남아 있어 풍속이 과대평가됩니다. 경고 결과를 운영 판단에 쓰면 안 됩니다.

## 구성
| 파일 | 내용 |
|---|---|
| `index.html`, `style.css` | 화면 구성 |
| `app.js` | 자료 로드, 수평·연직 렌더링, 48시간 시간 축 |
| `warning.js` | 경고 기준(임계값 한 곳에서 관리) |
| `data/base.bin` | int16, 배율 0.01 m/s, 순서 u·v·w × z × y × x |
| `data/meta.json` | 격자·고도·V5 인덱스 메타 |
| `scripts/export_base.py` | NetCDF → 웹용 binary 변환 |

## 경고 기준 (잠정)
- **경고**: 접근 고도(5–50 m, V5 주변 3×3 격자)의 최대 풍속 ≥ 8.8 m/s (17 kt)
- **주의**: ≥ 6 m/s (잠정값, 운영 기준 확정 필요)
- 근거: RWDI, *Development of Wind-Based Criteria for Vertiports* (AAMForum 80, 2024). 17 kt 지속풍은 FAA·EASA 제어 요건 근거. 횡풍·배풍·돌풍·난류 한계는 자료에 없어 **미적용**.

## 실시간 운영으로 바꾸려면 (다음 단계)
1. 예보 입력(예: 기상청 수치예보)과 MUKLIMO 실행 파이프라인을 구성합니다.
2. 시간별 결과를 `data/YYYYMMDDHH/` 아래에 같은 binary 형식으로 내보냅니다.
3. `app.js`의 `demoFactors()`를 제거하고 시간별 파일을 불러오도록 바꿉니다.
4. 실행 주기는 GitHub Actions 스케줄로 돌리고 결과를 Pages에 커밋합니다.

## 로컬 실행
```bash
python3 -m http.server 8000   # 브라우저에서 http://localhost:8000
```

## 주의
- API 인증키는 저장소에 넣지 않습니다.
- 공개 저장소에 모델 결과를 올리면 논문 투고 전 데이터 공개 정책에 걸릴 수 있습니다. 공개 전에 확인하십시오.
